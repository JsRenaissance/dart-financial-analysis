# 프로젝트 기획

## 질문
코스피 상장사의 재무 구조가 업종별로 어떻게 다른가?
2020~2024년 사이 어떤 업종이 어떤 패턴으로 변했는가?

## 데이터
- 출처: 금융감독원 OpenDART API
- 범위: 코스피 3개 업종, 약 300개사
- 기간: 2020~2024 사업보고서 (5개년)
- 기준: 연결재무제표(CFS), 없으면 별도(OFS)

## 산출물
- 수집 파이프라인 (재실행 가능)
- PostgreSQL 스키마 + 계정과목 매핑 테이블
- 분석 쿼리 5종
- Streamlit 대시보드
- README + 회고 글

## 일정
- Week 1: 수집 대상 확정
- Week 2: 수집·적재·매핑
- Week 3: 분석 쿼리
- Week 4: 대시보드·문서

## 하지 않을 것
- 투자 추천, 종목 선정
- 주가 데이터 결합 (범위 확대 방지)
